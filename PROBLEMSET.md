## How to Use This Catalogue

1. **Start at Phase 1** if you're new to competitive programming — build speed and implementation accuracy.
2. **Progress sequentially** through phases; each phase assumes mastery of previous patterns.
3. **Focus on patterns, not just solutions** — group problems by algorithm category to reinforce learning.
4. **Track your progress** — mark problems as solved and revisit unsolved ones periodically.
5. **Aim for consistency** — solve 2–3 problems daily rather than cramming.
